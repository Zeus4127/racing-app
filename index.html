Get the Android app

The Track Edge app is in private testing, so it is not in the Play Store yet. Ask the person who sent you this link for the TrackEdge APK file, then:

  1. Open the file on your Android phone (from Downloads or the message it came in).
  2. If asked, allow Install unknown apps for that app (Files, Chrome or your messages app).
  3. Tap Install. If Play Protect warns about an unknown developer, tap More details → Install anyway: it is a test build.
  4. Open Track Edge. It shows the same numbers as this website and updates itself when online.

iPhone or no APK? Open this website, tap Share → Add to Home Screen. It works like an app, offline too.
